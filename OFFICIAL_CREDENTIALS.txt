[1] 2-PORTAL APP LOGIN ARCHITECTURE & SECURITY RULES
--------------------------------------------------------------------------------
Security Policy:
  • NO GUEST ACCESS: Every user must be an authenticated member of the college.
  • NO FAKE / DUMMY LOGINS: Students can ONLY log in if their record has been
    imported via CSV or added to the official student database by the Admin / HOD.
  • PASSWORD: Default password for all official imported records is 00000.

Flow:
  1. Splash Screen
  2. Choose Login Portal:
     ├── [A] Student Portal (BS 4-Year & Intermediate)
     │    ├── Choose Level (BS Honors OR Intermediate)
     │    ├── BS Honors: Select Program & Semester -> Enter Official Roll No + Password (00000)
     │    └── Intermediate: Select Group (FSc/ICS/FA/ICOM) -> Enter Official Roll No + Password (00000)
     └── [B] Teacher & Staff Portal (Faculty, HODs, Administration)
          └── Enter Username / Faculty ID / Institutional Email + Password -> Auto-routes to:
               ├── Admin Dashboard (For Principal / Chief Admin)
               ├── HOD Dashboard (For Department Heads)
               └── Faculty Dashboard (For Teaching Faculty)

[5] HOW ADMIN / HOD IMPORTS STUDENTS (CSV BATCH UPLOAD)
--------------------------------------------------------------------------------
To allow students to log in:
1. Login as Admin (`principal` / `00000`) or HOD (e.g. `faiyaz` / `00000`).
2. Go to "Batch Student Import (CSV)" or "Official Registry".
3. Upload CSV file containing columns: Roll Number, Student Name, Reg Number, Father Name.
4. Once committed, all students in that CSV can immediately log into the Student Portal using their Roll Number and default password `00000`.
