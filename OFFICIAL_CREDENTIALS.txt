[1] 2-PORTAL APP LOGIN ARCHITECTURE & SECURITY RULES
--------------------------------------------------------------------------------
Security Policy:
  • NO GUEST ACCESS: Every user must be an authenticated member of the college.
  • NO FAKE / DUMMY LOGINS: Students can ONLY log in if their record exists in the
    official student database or has been imported via CSV by Admin or HOD.
  • ALL FACULTY CRAWLED FROM GGCMBDIN.EDU.PK ARE PRE-AUTHENTICATED:
    Every single professor listed on https://ggcmbdin.edu.pk/faculty.php can log in
    immediately using their Username, Faculty ID, or Institutional Email with
    default password "00000".
  • ROLE-BASED ACCESS CONTROL:
    - Principal / Admin ID: Auto-routes to Super Admin Dashboard.
    - Department Heads (HODs): Auto-routes to HOD Dashboard (with department CSV student import).
    - Teaching Professors: Auto-routes to Faculty Dashboard (attendance, course schedule, notices).

Flow:
  1. Splash Screen
  2. Choose Login Portal:
     ├── [A] Student Portal (BS Honors & Intermediate)
     │    ├── BS Honors: Program & Semester -> Roll Number + Password (00000)
     │    └── Intermediate: Group (FSc/ICS/FA/ICOM) -> Roll Number + Password (00000)
     └── [B] Teacher & Staff Portal (Faculty, HODs, Administration)
          └── Enter Username / Faculty ID / Email + Password (00000) -> Auto-routes to:
               ├── Admin Dashboard (Principal / Executive Admin)
               ├── HOD Dashboard (All 15 Department Heads)
               └── Faculty Dashboard (All Teaching Professors)
