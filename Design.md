# Design — GGC Mandi Bahauddin

## Mode
Documentation Mode only.
Do NOT write production code until:
"START PRODUCTION"

## Design Goal
The app must look like an official college application,
not a generic student app.

## Branding
- Follow the official GGC Mandi Bahauddin website.
- Use the website's existing color palette.
- Use official college logo/branding.
- Maintain consistent visual identity across all screens.
- Do not introduce unrelated colors such as bright red, pink,
  purple, neon or gaming-style colors.

## UI Style
- Clean
- Professional
- Modern
- Minimal
- Academic
- Easy to navigate
- Suitable for official college administration

## Typography
- Professional and highly readable.
- Clear hierarchy between headings, subtitles and body text.
- Avoid decorative fonts.

## Components
Use a consistent design system for:
- Top bars
- Bottom navigation
- Cards
- Buttons
- Input fields
- Tabs
- Dialogs
- Lists
- PDF/resource cards
- Notifications

## Navigation
Primary bottom navigation:
- Home
- Academics
- Notices
- College
- Profile

## States
Every data-driven screen must handle:
- Loading
- Empty
- Error
- Success
- Offline

## Animations
- Subtle and purposeful.
- Avoid excessive animations.
- Prioritize performance.

## Accessibility
- Readable text
- Proper contrast
- Touch-friendly controls
- Clear icons and labels

## Responsive UI
The layout should work properly across supported Android
screen sizes without breaking or overlapping.

## Important
Do not invent a new visual identity.
When unsure about a visual decision, follow the official
college website's existing design language.
